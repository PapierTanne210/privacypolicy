# Privacy Policy — Glacier

**Last updated:** August 30, 2026

This Privacy Policy explains what data **Glacier** ("the Bot") collects, how it is used, and how it is protected. It applies to the Discord server(s) that have added the Bot.

By using a server that has Glacier installed, or by interacting with the Bot directly, you agree to the collection and use of information as described in this policy.

---

## 1. Who This Applies To

Glacier is intended for use on Discord in accordance with [Discord's Terms of Service](https://discord.com/terms) and [Community Guidelines](https://discord.com/guidelines), which require all users to be at least 13 years old (or the minimum age required in your country). We do not knowingly collect data from anyone below that age.

---

## 2. Data We Collect

| Data | Purpose |
|---|---|
| Discord User ID | Identifying members for leveling, moderation, and tickets |
| Discord Server (Guild) ID | Keeping server data and settings separate |
| Discord Role IDs | Assigning/removing level-reward and VIP-related roles |
| XP and level per user | Leveling system, including birthday and VIP-role XP bonuses |
| Birthday (day/month), if provided by a user | Birthday announcements and XP bonus |
| Blacklist entries (user ID + username) | Server moderation |
| Auto-response triggers and auto-reaction rules configured by staff | Running staff-configured automated replies/reactions |
| Ticket records (which member opened a ticket) | Operating the support-ticket system |
| Moderation action records (kicks, bans, timeouts performed via the Bot) | Server moderation and accountability |

We do not collect Discord passwords, email addresses, payment information, or IP addresses.

### Message content

Glacier reads message text in real time to check it against staff-configured auto-response triggers, to detect @mentions for auto-reactions, and to detect the word "download" for an automatic info reply. This content is processed transiently and is **not stored** in our database.

The one exception is a hidden **"honeypot" anti-raid channel**, not intended for use by legitimate members. If a message is posted there, its text and any attached images are automatically forwarded to a private staff moderation-log channel (within Discord) and the sender is removed from the server. This exists solely to catch raid bots, scammers, and spam accounts, and message content is never used to train machine learning or AI models.

---

## 3. How We Use Data

We use the data above only to operate Glacier's features: welcome messages, leveling/leaderboards, birthday tracking, moderation tools, ticket support, and staff-configured automated responses/reactions. We do not sell your data and do not use it for advertising.

---

## 4. Where Data Is Stored, and For How Long

All persistent data (XP/levels, birthdays, blacklist entries, auto-response/auto-reaction configuration, ticket records) is stored in a local database on the server(s) we use to host the Bot. It is not shared with, or accessible to, any third party.

- Data is **not** deleted on a fixed 30-day schedule — leveling, birthday, and configuration data is kept for as long as the Bot remains in your server.
- When a member leaves a server, their leveling and auto-reaction data tied to that server is automatically deleted.
- Blacklist entries and moderation records may be retained longer for security and abuse-prevention purposes, even after a member leaves.
- Honeypot logs are kept in that server's own private moderation-log channel, subject to Discord's own message retention and that server's staff practices.
- The storage disk/volume used to host this data is encrypted at rest.
